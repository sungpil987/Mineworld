## 구조 분석

원작은 필드를 이동하고 목표 광물을 선택해 채굴하는 파밍 RPG다. 돈으로 속도·위력·광물 가치를 성장시켜 같은 광물을 훨씬 빨리 처리하고 더 높은 광산을 방문한다. 광물의 체력과 채굴 가능 횟수는 다른 개념이다. 채굴 1회가 성공할 때 보상을 주고, 잔량이 모두 소진되면 광물이 고갈된다.

관찰한 큰 축은 다음과 같다.

| 축 | 문서에 나타난 구조 | 마인월드 적용 |
| --- | --- | --- |
| 기본 성장 | Speed / Power / Skill | 속도·힘·솜씨의 독립적 효과 |
| 탐험 | 계단, 입장권, 봉인석, 다양한 광산 | 3개 독자 테마, 합계 레벨 봉인 해제, 각 5층 |
| 광맥 | 가치·단단함·반복 채굴 횟수 | 24종, 광맥마다 2~5회 채굴 |
| 전투 | 보스 탄막, 생명석, 회피 | B5 수호자와 생명 결정, 탄막과 바닥 경고 |
| 스킬 | 광역/행운/자동 채굴 등 | 광역 강타, 행운 채굴, 이동 돌진 |
| 코스튬 | 채굴/이동/보스전 성능 변화 | 기본/이동/보호/수익 특화 4종 |
| 환생 | 기본 성장 리셋과 영구 성장 | Lv.90, 영혼 결정과 영구 강화 |
| 수집 | 광물 도감과 숨은 요소 | 발견형 도감, 업적 |
| 장기 목표 | 시련, 일일 광산, 각인 등 | 후속 확장 대상 |

원작의 가격·맵·몬스터·스킬 전체를 복제한 제품이 아니다. 이름, 스프라이트, UI, 효과음과 수치는 독자적으로 제작했다. 이번 버전의 목표는 전체 라이브 서비스 볼륨이 아니라, 이동 → 채굴 → 강화 → 하강 → 보스 → 환생의 완결된 한 사이클이다.

## 수치 설계

- 기본 채굴 위력: `8 + 힘 × 3.8`, 영구 곡괭이 강화마다 +15%
- 채굴 주기: `0.72 / (1 + 속도 × 0.08)`초, 최저 0.055초
- 채굴 수익: `광물 기본 가치 × (1 + 솜씨 × 0.12) × 영구 수익 배율 × 코스튬 배율`
- 능력치 강화 비용: `ceil(22 × 1.115^현재레벨)`
- 광산별 가치 배율: 1 / 6 / 28, 강도는 가치보다 완만하게 성장
- 일반층 계단: 해당 층에서 채굴 성공 12회
- 환생 보상: `max(1, floor(sqrt(이번 탐험 총수익 / 9000)) + 이번 탐험 보스 처치 × 3)`
- 오프라인 보상: 측정된 활성 플레이 초당 수익의 25%, 기본 2시간, 영구 금고로 연장

첫 광맥과 보석을 시작 지점 근처에 배치했다. 높은 희귀도는 낮은 빈도로 생성되지만 3층 이후에 최상위 광물을 하나 보장한다. 광역 강타는 플레이어 주위에만 작용한다. 보스 탄환에는 피격 무적을 두어 중첩 피격으로 즉시 사망하지 않도록 했다.

## 알려진 경계와 후속 확장

- 싱글/오프라인 전용. 서버, 공동 플레이, 랭킹, 결제, 광고 미구현
- 3개 테마/24종은 첫 버전 범위. 무한 광산, 각인, 시련, 퍼즐, 일일 광산 미구현
- 충돌 벽 미로 대신 열린 필드와 랜드마크 기반 탐험. 광물은 이동 장애물이 아님
- 오프라인 보상은 플레이 수익 추정치이며 실제 백그라운드 시뮬레이션이 아님
- 자동 저장은 기기별 로컬 저장. 저장 코드로 수동 이동 가능
- 코어 단위 테스트와 Chromium 모바일 UI 자동 테스트는 실제 Android 기기의 전체 호환성을 보장하지 않음
- 장기 경제는 여러 환생과 영구 강화의 실제 플레이 데이터를 보고 계속 조정해야 함
