# MINEWORLD 2.0 · 마인월드

인터넷 없이 즐기는 세로형 광산 탐험 RPG. 필드를 이동하며 광물을 채굴하고, 광산별 장치·보스·시련·환생·각인으로 성장을 이어갑니다. 스프라이트, UI, 배경, 효과음과 음악은 코드로 직접 제작했습니다.

## APK 설치 / 업데이트

1. **Actions → Android APK**의 최신 성공 실행을 엽니다.
2. **Artifacts → Mineworld-v2.0-APK** ZIP을 다운로드합니다.
3. 압축을 풀고 `app-debug.apk`를 설치합니다.

Android 8.0 이상과 최신 Android System WebView가 필요합니다. 1.0과 같은 패키지 ID를 사용합니다. 테스트 서명 키는 Actions 캐시로 이어가며, 캐시가 유지되면 기존 앱 위에 업데이트할 수 있습니다. 캐시 삭제 등으로 키가 바뀐 경우 앱을 삭제하기 전에 반드시 **설정 → 내보내기**로 저장 코드를 백업하세요. 정식 배포에는 별도 릴리스 서명이 필요합니다.

## 2.0의 변화

- **20개 탐험 지역**: 자유·황금·다이아몬드·판타지·사막·숲·얼음·바다·용암·우주·유적·시간·천상·심연·전자·무한·차원 광산, 숨겨진 방, 눈덮인 산, 전자광산 비밀의 방
- **기본 광물 66종**의 가격·광맥 잔량·형태와 도감 등급. 기존 게임 고유 광물 13종도 별도 기록으로 보존하여 총 79개 도감 항목
- 광산별 5층/6층/10층 및 무한층, 입장권·입장료·채굴 가능한 봉인석, 보스 처치에 따른 봉인 완화
- 상자 변환, 보물지도와 비밀 열쇠·물약·보물, 광산 폭탄, 블랙홀, 시간 지름길, 유적 스위치 퍼즐, 상자 밀기, 천상 비망록과 세 문, 전자 이진수 암호와 포탈 순서
- **17종 코스튬**, 이동/채굴 방식 변경, 계절/기념일 구매 조건, 코스튬별 리미트 해제
- **33개 보스 정의**와 각기 다른 패턴: 돌진·회전탄·유도탄·텔레포트·레이저·지진파·구역 공격·운석·소환수·슬로우 등
- **시련 7종**: 속도, 속도 하드, 힘, 힘 하드, 힘2, 힘2 하드, 기술. 미로 경로 탐색과 제한시간, 임시 능력치 상한, 스킬/코스튬 제한
- **일일 광산 8종** 순환: 채광 배틀, 경주, 눈덮인 산, 패션쇼, 버섯 채굴, 버닝 데이, 보스 러시, 보석 축제. 한국시간 자정 갱신
- 골드/영혼/촉매/각인 상점, 자동 광역 채굴·연속 채굴·확률 채굴·동행 분신·미다스 수익
- 부스트·환생 보너스·전투당 한 번 부활, 일일 보급과 보스 처치를 통한 촉매 획득
- 환생·징표·도감 보너스, **각인의 사원에서 다섯 블록 퍼즐과 사신 회피**, 차원 봉인 7개
- 차원의 곡괭이 발견·수리·옵션 재부여·옵션 보관과 교환·옵션 고정, 각인 강화
- 능력치당 **20억**, 합계 **60억** 만렙, 효율적인 MAX/균등 강화, 만렙 능력치를 소모하는 압축
- 배경 음악, 광물별 픽셀 형태, 보스 실루엣, 광산별 색감, 레이더·나침반, 감소 효과 설정

상세 구현 범위와 참조 사진의 기능 대응은 [docs/FEATURE_COVERAGE.md](docs/FEATURE_COVERAGE.md)를 참고하세요. 원작의 리소스·고유 화면·캐릭터 디자인을 가져오지 않았으며 가격/입장 조건 외의 전투·경제 수치는 마인월드에 맞게 재설계했습니다.

## 조작

- 바닥: 이동. 장애물이 있는 미로에서는 격자 경로를 탐색합니다.
- 광물: 접근 후 자동 채굴. 잔량이 소진되면 돌로 바뀌며, 잡석 제거가 있으면 사라집니다.
- 상자·장치·퍼즐: 가까이 다가가면 상호작용합니다.
- 계단: 목표를 달성한 후 버튼으로 이동하고, 도착해 다시 누르면 내려갑니다.
- 보스: 생명석을 채굴하면 큰 피해를 주고 플레이어 체력을 회복합니다. 생명석으로 일부 탄막을 가릴 수 있습니다.
- 광산 변경: 일반 광산 외에 시련/일일/사원 탭이 있습니다.
- 탐험 가방: 책 사용, 옷장, 차원 장비, 패션쇼 체험 코스튬을 찾을 수 있습니다.

## 저장과 이전 버전 호환

저장 키와 Android 패키지 ID는 1.0과 같습니다. v1 저장을 읽으면 골드·영혼·성장·기존 강화·코스튬·도감·업적을 보존하면서 v2로 변환합니다. 기존 서리/잿불 해금은 얼음/용암 광산으로 이전합니다. 구리 기록은 동으로, 다른 기존 광물 기록은 이름이 같은 새 항목 또는 별도 보존 항목으로 이전합니다.

10초마다, 구매/성장/이동 화면 전환 시, 앱을 떠날 때 저장합니다. 광맥 잔량·현재 층·플레이어 위치·보스 체력·퍼즐·제한시간도 보관합니다. 저장 오류 시 직전 유효 백업을 시도합니다. **설정 → 내보내기 / 코드 복원 / 이전 자동 저장 복구**를 제공합니다.

환생과 각인은 플레이어가 명시적으로 확인하는 성장 초기화입니다. 각각 확인 화면에 초기화/보존 항목을 표시합니다. 업데이트 시 저장 마이그레이션과 이 성장 초기화는 별개입니다.

## 개발과 검증

```sh
node --test tests/core.test.cjs
python3 -m pip install -r tests/requirements.txt
python3 -m playwright install --with-deps chromium
python3 tests/browser_smoke.py
```

웹 플레이 확인:

```sh
python3 -m http.server 8765 --directory app/src/main/assets/game
```

Android: JDK 17, Android SDK 35, Gradle 8.9.

```sh
gradle --no-daemon :app:assembleDebug
```

소스 구조:

- `data.js`: 광물·광산·아이템·코스튬·보스·시련 카탈로그
- `core.js`: 경제·도감·환생·각인·구매·저장 마이그레이션과 검증
- `game.js`: 실제 필드·채굴·보스 AI·장치·퍼즐·화면·수명주기
- `MainActivity.java`: 외부 리소스를 차단하는 오프라인 Android 호스트와 시스템 바 여백
- `tests/core.test.cjs`: 21개 경제·대규모 강화·저장 이전·장기 진행 테스트
- `tests/browser_smoke.py`: 실제 모바일 페이지의 조작·저장·봉인·보스·퍼즐·각인·시련·장비·레이아웃 검증

## 운영 범위

완전한 오프라인 싱글 플레이입니다. 일일 광산의 라이벌과 동행 분신은 로컬 게임 캐릭터입니다. 온라인 플레이어 접속, 서버 랭킹, 실제 광고 SDK와 현금 결제는 연결하지 않습니다. 촉매·아이템은 게임 보상으로 획득하며, 과거 삭제된 시즌/이벤트/픽셀 코스튬은 역사적 기능으로 간주합니다. 실기기 호환성과 장기 경제 밸런스는 실제 플레이를 바탕으로 추가 검증이 필요합니다.
