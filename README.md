# MINEWORLD · 마인월드

세로 화면으로 즐기는 오프라인 광산 탐험 RPG. 바닥을 터치하면 이동하고, 광물을 터치하면 접근해 광맥이 소진될 때까지 자동 채굴합니다. 원작의 이미지·음원·맵을 사용하지 않고 자체 픽셀 드로잉과 효과음으로 제작했습니다.

## APK 설치

1. 이 저장소 상단 **Actions → Android APK**를 엽니다.
2. 최신 실행에 초록 체크가 표시되면 실행 상세 화면 아래 **Artifacts → Mineworld-v1.0-APK**를 다운로드합니다.
3. ZIP 압축을 해제한 뒤 `app-debug.apk`를 Android 휴대폰에 설치합니다.

`push` 시 자동 빌드되며 **Run workflow**로 수동 실행할 수도 있습니다. Android 8.0 이상과 최신 Android System WebView가 필요합니다. 별도 서버·로그인·광고·결제는 없습니다.

처음 실행 시 자동 빌드가 보이지 않으면 Actions 화면에서 워크플로를 활성화하고 실행하세요. APK는 테스트 서명입니다. 동일 설치의 업데이트를 돕도록 Actions 캐시에 서명 키를 유지하지만, 캐시가 삭제되면 키가 바뀔 수 있습니다. 그런 경우 **설정 → 내보내기**로 저장 코드를 보관한 뒤 재설치하고 복원하세요. 정식 배포 전에는 별도의 영구 릴리스 서명을 설정해야 합니다.

## v1.0 플레이 콘텐츠

- 캐릭터 이동·자동 채굴·카메라 추적·미니맵·광맥 소진·파편과 골드 연출
- 이끼빛 갱도 / 서리 수정굴 / 잿불 심장부: 각각 5개 층, 고유한 광물 8종과 보스
- 24종 광물 도감, 15개 업적과 영혼 결정 보상
- 속도·힘·솜씨 강화: 1회 / 10회 / MAX, 선택 가능한 균등 강화
- 돌진 / 광역 강타 / 행운 채굴: 합계 Lv.15 / 30 / 60에 해금
- B5 보스: 방사형 탄막과 바닥 경고 공격을 피하며 생명 결정 파괴
- 합계 Lv.90 환생: 골드와 기본 능력치 초기화, 영혼 결정 지급
- 영구 강화 3종, 플레이 성능이 다른 코스튬 4종
- 실제 활성 채굴 수익 기반 오프라인 보상: 25% 효율, 기본 최대 2시간
- 자동 저장·이전 저장 백업·코드 내보내기/복원·효과음·진동·효과 줄이기

일반층에서는 광물을 12회 캐면 계단이 열립니다. **다음 층** 버튼을 누르면 계단으로 이동하고, 도착한 뒤 다시 누르면 내려갑니다. 보스는 일반층에 반복해서 나타나지 않고 B5에서만 등장합니다. 생명 결정 하나를 파괴하면 보스 최대 체력의 19%를 깎습니다. 보스에 직접 곡괭이질을 할 수도 있습니다.

광산 해금 조건은 능력치 합계 45 / 120입니다. 환생 후에도 해금은 유지됩니다. 기본 능력치는 각 500레벨까지 강화할 수 있습니다. 후반 확장과 장기 밸런스 조정은 다음 버전의 대상입니다.

## 저장 보존

10초마다, 성장/구매/화면 전환 시, 앱을 떠날 때 저장합니다. 골드·성장·도감뿐 아니라 현재 층, 광맥 잔량, 플레이어 위치와 보스 체력도 보관합니다. 환생해도 영구 강화·코스튬·광산 해금·도감·업적은 유지됩니다. 보스전 사망 시 골드 5%를 잃고 해당 광산 B1으로 돌아갑니다.

저장은 기기 로컬에 있습니다. 앱 삭제 시 손실될 수 있으므로 **설정 → 내보내기**의 저장 코드를 별도로 보관하세요. 가져오기는 확인 화면을 거쳐 현재 진행을 교체합니다. 손상된 주 저장은 이전 백업으로 읽기를 시도하며, 설정에서도 이전 자동 저장을 복원할 수 있습니다.

## 개발 / 검증

```sh
node --test tests/core.test.cjs
python3 -m http.server 8765 --directory app/src/main/assets/game
# http://localhost:8765 에서 조작 및 화면 확인
```

Android 빌드: JDK 17, Android SDK 35, Gradle 8.9 설치 후 실행합니다.

```sh
gradle --no-daemon :app:assembleDebug
```

구조:

- `core.js`: 능력치·경제·환생·상점·업적·저장 정규화. Android 없이 단위 테스트 가능
- `game.js`: 실제 이동·채굴·보스 AI·픽셀 드로잉·UI·저장 수명주기
- `MainActivity.java`: 오프라인 Android WebView 호스트. 외부 탐색과 외부 리소스 요청 차단
- `tests/core.test.cjs`: 경제·영구 진행·오프라인 한도·손상 데이터 검증
- `tests/browser_smoke.py`: 모바일 브라우저의 실제 채굴, 저장 복구, 보스·환생 흐름 검증
- `docs/DESIGN.md`: 참조 게임의 구조 분석과 이번 구현 범위

Android 호스트에는 인터넷 권한이나 파일 공유 권한이 없습니다. 원격 콘텐츠와의 JavaScript 브리지 혼용을 막고 로컬 페이지의 진동 요청만 네이티브로 전달합니다. 웹 페이지에서 저장 코드 복사/붙여넣기는 OS의 텍스트 선택 메뉴로 처리합니다.
